# Ollamate Project Context

## Project Overview

Ollamate is an open-source, ChatGPT-like desktop client built around Ollama. It provides a local, privacy-focused experience for interacting with LLM models like Llama 3, Qwen2, and Phi3. The application is cross-platform, primarily targeting macOS (Apple Silicon), with plans for Windows and Linux.

### Key Technologies
- **Framework**: Electron (for cross-platform desktop capabilities).
- **Frontend**: React 19, React Router, Redux Toolkit (for state management).
- **Styling**: Tailwind CSS v4, shadcn/ui, Radix UI primitives.
- **Backend (Main Process)**: Node.js, `better-sqlite3` for local storage, Drizzle ORM for database schema and migrations.
- **IPC / Communication**: tRPC via `electron-trpc-experimental` for type-safe communication between the renderer and main processes.
- **AI Integration**: Vercel AI SDK (`@ai-sdk/react`, `ai-sdk-ollama`) for chat stream and message management.
- **Build Tooling**: Vite (with `vite-plugin-electron`), TypeScript, ESLint, Electron Forge.
- **Package Manager**: Yarn.

## Architecture

The project strictly separates the Electron main process and the React renderer process, communicating via tRPC.

- `src/`: Contains the React renderer process code.
  - `components/`: UI components, including Radix UI and shadcn components (`ui/`).
  - `lib/`: Utility functions, tRPC client configuration, and API wrappers (`aiSdk.ts`, `ollamaApi.ts`, etc.).
  - `redux/`: Redux store configuration and slices (`chatSlice`, `messageSlice`, etc.).
  - `routes/`: React Router page components.
- `electron/`: Contains the Electron main process code.
  - `main.ts`: The entry point for the Electron app, window creation, and IPC handlers.
  - `preload.ts`: Exposes secure APIs to the renderer.
  - `api/`: tRPC server definitions and routers.
  - `db/`: SQLite database setup, Drizzle ORM schema (`schema.ts`), and data services.
- `drizzle/`: Contains SQL migration files generated by Drizzle Kit.

## Building and Running

Make sure you have [Ollama](https://ollama.com) installed and at least one model downloaded (e.g., `ollama run phi3`).

Install dependencies using Yarn:
```bash
yarn install
```

### Key Scripts
- **Start Development Server**: 
  ```bash
  yarn dev
  ```
  Starts Vite for the renderer process and compiles/runs the Electron main process.
- **Build for Production**:
  ```bash
  yarn build
  ```
  Type-checks and builds the React app and Electron scripts.
- **Start Compiled App**:
  ```bash
  yarn start
  ```
  Starts the app using Electron Forge.
- **Linting**:
  ```bash
  yarn lint
  ```
  Runs ESLint across the project.
- **Database Migrations**:
  ```bash
  yarn db:generate
  ```
  Generates new Drizzle SQL migrations based on changes to `electron/db/schema.ts`.
- **Packaging (Mac)**:
  ```bash
  yarn make-arm64
  yarn make-x64
  ```

## Development Conventions

- **State Management**: Utilize Redux Toolkit slices (`src/redux/slice/`) for global UI and entity state, keeping components as pure as possible.
- **Styling**: Use Tailwind CSS utility classes. For reusable components, adhere to the `shadcn/ui` pattern located in `src/components/ui/`.
- **Database Changes**: Any modifications to the local SQLite database schema must be done in `electron/db/schema.ts`. After changes, always run `yarn db:generate` to create the corresponding migration.
- **TypeScript & Linting**: The codebase enforces strict TypeScript. ESLint is configured to error on unused variables (unless prefixed with `_`).
- **Communication**: Avoid raw `ipcRenderer.send`/`ipcMain.handle` where possible. Instead, add new procedures to the tRPC router in `electron/api/` to ensure end-to-end type safety between the main and renderer processes.
